EDIT 3 — export the two price helper functions (THIS IS WHAT BROKE THE BUILD)
--------------------------------------------------------------------------------
Your Railway build log error:

    No matching export in "server/routes.ts" for import "fetchStockPrices"
    No matching export in "server/routes.ts" for import "fetchCryptoPrices"

Cause: household-routes.ts imports these two functions, but in
routes.ts they're declared without `export`. Scroll to the very bottom
of the file, under this comment:

    /* ============ Price helpers ============ */

You'll see two function declarations that currently start like this:

    async function fetchStockPrices(symbols: string[]): Promise<Record<string, { price: number; dayChangePct: number; ... }>> {

    async function fetchCryptoPrices(symbols: string[]): ... {

Add the word `export` immediately before `async` on BOTH of them, so
they read:

    export async function fetchStockPrices(symbols: string[]): Promise<Record<string, { price: number; dayChangePct: number; ... }>> {

    export async function fetchCryptoPrices(symbols: string[]): ... {

Do not change anything else about either function — just add the one
word `export` at the start of each declaration line.
